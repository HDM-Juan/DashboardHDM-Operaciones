## 🔎 Posibles causas y soluciones

### **Causa 1: Folios no coinciden exactamente**

**Problema:** 
En Ventas aparece: `A-2024-0012` (con guiones)
En Egresos aparece: `A20240012` (sin guiones)

**Solución:**
Normalizar los folios antes de comparar (próxima actualización)

### **Causa 2: Nombres de columnas diferentes**

**Problema:**
Buscando `row['Folio Anticipo']` pero la columna se llama `row['Anticipo']`

**Verificar en los logs:**
```javascript
- Detalle: [{
    anticipo: null,  ← Si es null pero debería tener valor
    recepcion: null
  }]
```

### **Causa 3: Fechas fuera de rango**

**Problema:**
El periodo seleccionado es "Este Mes" (feb 2026)
Pero los egresos tienen fechas de enero 2026

**Verificar:**
```
📅 Periodo: este-mes → 2026-02-01 a 2026-02-17
📅 Excluidos (fuera de rango): 812
```

**Solución:**
Cambiar el periodo en Config a "Últimos 30 días" o "Este Año"

### **Causa 4: Columna oculta manualmente**

**Verificar:**
En la tabla hay botones de columnas (📗 Folio, 📅 Fecha, etc.)
Si "💰 Costo Venta" está deshabilitado → activarlo

## 📊 Lógica de vinculación

Los egresos se relacionan con ventas de 2 formas:

### **Forma 1: Por Folio Anticipo**
```javascript
// En Ventas
Folio Venta: "V-2024-0123"
Folio Anticipo: "A-2024-0012"

// En Egresos
Anticipo: "A-2024-0012"  ← Debe coincidir

// Resultado
Egreso se marca como "costo_venta" de "V-2024-0123"
```

### **Forma 2: Por Folio Recepción**
```javascript
// En Ventas
Folio Venta: "V-2024-0123"
Folio Recepción Final: "R-2024-0034"

// En Egresos
Recepción: "R-2024-0034"  ← Debe coincidir

// Resultado
Egreso se marca como "costo_venta" de "V-2024-0123"
```
