### 3. ✅ Desglose de folios ahora es MODAL

**Cambio:** Ya no expande inline, ahora abre **modal con fondo oscuro**

**Características:**
- Fondo oscuro: `rgba(0,0,0,0.85)` con blur
- Modal con fondo claro: `#f8f9fa`
- Borde verde: `#4CAF50`
- Botón ✕ para cerrar
- Click fuera del modal también cierra
- Se puede abrir/cerrar sin recargar tabla

**Cómo funciona:**
1. Click en badge de folio (📗 V-2024-0123)
2. Se abre modal centrado
3. Resto de la página se oscurece
4. Click en ✕ o fuera del modal para cerrar

**Logs:**
```javascript
📋 toggleExpandRow llamado para: V-2024-0123
📂 Abriendo modal de desglose para: V-2024-0123
```

## 🚨 Problemas comunes y soluciones

### **Problema 1: Panel de filtros no se abre**

**Síntomas:**
```
🎛️ toggleDimPanel: dim-panel-dispositivo
❌ Panel no encontrado: dim-panel-dispositivo
```

**Solución:**
- Verificar que estás en la sección de Ventas
- El panel solo existe cuando Ventas está activa

---

### **Problema 2: Gráfica mixta no visible**

**Síntomas:**
```
🔍 Verificación de elementos visuales:
  chart-mixed-dim: true visible: false
```

**Solución:**
```javascript
// En consola ejecutar:
document.getElementById('section-ventas').classList.add('active-section');
```

---

### **Problema 3: Toggles de periodo no funcionan**

**Síntomas:**
```
⚠️ No se puede inyectar periodos - chart o datos faltantes
```

**Causa:** La gráfica principal no se creó

**Verificar:**
```
✅ Gráfica principal de ventas creada, window._ventasMainChart: true
```

**Si es `false`:**
- La sección de Ventas no se actualizó completamente
- Hacer clic en otra sección y volver a "📗 Ventas"

---

### **Problema 4: Filtros no actualizan gráficas**

**Síntomas:**
- Filtro se marca correctamente
- Tabla se filtra
- Pero gráficas no cambian

**Verificar en logs:**
```
✅ Después filtro dimensiones: 5 registros
🎨 Actualizando gráfica mixta...
📊 updateMixedChart ejecutando...
✅ Gráfica mixta actualizada
```

**Si NO aparece "Actualizando gráfica mixta":**
- updateVentasView no está llamando a updateMixedChart
- Bug crítico - reportar con logs
